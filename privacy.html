1. YouTube API Services

Shorts Factory uses YouTube API Services. By using Shorts Factory you agree to the YouTube Terms of Service. Information obtained through YouTube API Services is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

쇼츠공장은 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관에 동의하는 것으로 보며, YouTube API로 받은 정보에는 Google 개인정보처리방침이 적용됩니다.

2. Who uses this app

Shorts Factory is a personal, single-user desktop tool. It runs only on the operator's own PC and is used only to manage the operator's own YouTube channel. It is not offered to the public.

운영자 본인 PC에서 본인 채널만 관리하는 1인용 프로그램이며, 다른 사람에게 제공하지 않습니다.

3. Information we access

When the operator connects a Google account (OAuth 2.0), Shorts Factory requests these permissions:

  • youtube.upload — to upload videos that the operator has reviewed and approved.
  • youtube.readonly — to read the connected channel's name and to search public videos.

From YouTube API Services the app accesses: the connected channel's title, the ID of each video it uploads, and public search results (video title, channel name, thumbnail, publish date, view count, duration).

구글 계정 연결 시 '동영상 업로드'와 '계정 보기' 권한만 요청합니다. 연결된 채널 이름, 올린 영상의 ID, 공개 검색 결과(제목·채널명·썸네일·날짜·조회수·길이)만 다룹니다.

4. How information is used, stored and shared

  • Stored locally only. The OAuth token and the IDs of uploaded videos are stored only on the operator's PC (files in the app folder). There is no server or cloud database.
  • Search results are not stored. They are displayed on screen and discarded; videos are never downloaded or re-uploaded.
  • No sharing or selling. Information obtained from YouTube API Services is not shared with, sold to, or transferred to any third party, and is not used for advertising.
  • Other services used for content creation (they never receive YouTube API data or Google account data): Anthropic Claude (rewriting the story text into a script), Microsoft Edge text-to-speech (voice-over), Pixabay and いらすとや (free images).
  • No cookies or tracking. The app does not use cookies, analytics or tracking.

토큰과 올린 영상 ID는 운영자 PC에만 저장되고 서버는 없습니다. 검색 결과는 저장하지 않으며 영상을 내려받거나 다시 올리지 않습니다. YouTube API로 받은 정보는 누구에게도 공유·판매하지 않고 광고에 쓰지 않습니다. 대본·음성·그림을 만들 때 쓰는 외부 서비스(Anthropic Claude, Microsoft Edge TTS, Pixabay, いらすとや)에는 YouTube·Google 계정 정보를 보내지 않습니다. 쿠키·분석·추적을 쓰지 않습니다.

5. Revoking access and deleting data

  • Press "연결 끊기" (Disconnect) on the app's YouTube Upload screen. This revokes the token at Google and deletes it from the PC.
  • Or revoke access at any time from the Google security settings page: https://security.google.com/settings/security/permissions
  • All locally stored data can be deleted by deleting the app folder (or the token.json file and the data folder). The only YouTube API data kept is the ID of each video the app uploaded to the operator's own channel; deleting a job in the app deletes its record.

앱의 '연결 끊기' 버튼(구글 쪽 권한 취소 + PC의 토큰 삭제) 또는 Google 보안 설정 페이지에서 언제든 권한을 철회할 수 있습니다. 앱 폴더(또는 token.json과 data 폴더)를 지우면 모든 정보가 삭제됩니다.
